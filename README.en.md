# Whale-chan for rEFInd

[简体中文](README.md) | **English**

A whale-girl themed rEFInd boot menu, with operating system icons, function buttons, and a matching background.

## Installation

Copy the `whalechan` folder into rEFInd's `themes/` directory, then add this line to `refind.conf`:

```conf
include themes/whalechan/theme.conf
```

Back up your configuration and disable your previous theme before installation. The default resolution is 2560×1440; if unsupported, change it to `resolution max` in `theme.conf`.
