# Whale-chan for rEFInd

**简体中文** | [English](README.en.md)

鲸鱼娘风格的 rEFInd 启动主题，包含系统图标、功能按钮和配套背景。

## 安装

将 `whalechan` 文件夹放进 rEFInd 的 `themes/` 目录，在 `refind.conf` 中添加：

```conf
include themes/whalechan/theme.conf
```

安装前备份原配置并停用旧主题。默认分辨率为 2560×1440，不支持时可在 `theme.conf` 中改成 `resolution max`。
