# 功能动作与角标适配

新增动作通过内置 imagegen 绘制：about 拿手册讲解、hidden 文件夹后探头、exit 挥手告别。沿用 tools 双手拿扳手、restart 抱重启箭头、shutdown 抱月亮睡觉。共六套人物姿势，覆盖 23 个功能/工具/设备图标。

使用原有 SVG 卡片布局添加统一白底右下角角标；所有功能均有独立符号。按钮 96px，卷标 48px；系统图标保持原版。PNG 静态动作，不是动画。
