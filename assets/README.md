# 素材目录

只收录当前定稿使用的一套原画，不包含弃用动作或早期修复版本。

- `art/os/`：7 张系统图标原画，holder.png 是已修复嘴唇的手持牌版本。
- `art/functions/`：6 张功能原画；hidden.png 是最终选定的文件夹后探头。
- `badges/`：23 个可编辑 SVG 功能角标。
- `os-logos/`：手持牌实际使用的社区系统标志。
- `references/delighted.png`：最初使用的 Q 版人物参考，来源为 [dsh-deep-whale 的 delighted-cutout.png](https://github.com/Small-tailqwq/dsh-deep-whale/blob/main/maid-atelier/assets/icons/delighted-cutout.png)。
- `prompts/`：系统和功能原画的绘制提示词与记录。
- `icon-map.json`：构建和预览使用的图标映射。
- `manifest.json`：素材的尺寸（字节）与 SHA256 校验值。

背景原图已经保存在 `../whalechan/background.png`，不再复制第二份。选中框、箭头、鼠标和透明占位在 whalechan/ 中作为原生静态素材保留。
